Definición de Página Web

  • Una página web, lo podemos definir como un documento de texto con marcas o etiquetas.
  • Estas etiquetas lo que permiten es poder presentar información al usuario: texto, imágenes, audios, vídeos, tablas, etc.
  • Estas etiquetas o marcas se llamas tags, y NO ES UN LENGUAJE DE PROGRAMACIÓN A LO SUMO como podría ser Java, Python, PHP, etc.
  • Estas páginas están pensadas para que sean visibles desde cualquier navegador web.
  • Los navegadores por lo tanto, se encargara´n de interpretar estas marcas con el fin de que los usuarios puedan visaulizar y ver su contenido de manera correcta.

Definición de HTML

El acrónimo HTML, viene dado del nombre HyperText Machup Language, es decir, Lenguaje de Marcado de Hipertexto.
Esto quiere decir, que las páginas web son un conjunto de páginas con etiquetas que están vinculadas entre ellas a través de hiperenlaces o hipervínculos.
Las características que tenemos que tener en cuenta son las siguientes:
  • Que la estructura HTML viene definida por la W3Consortium
  • Se pueden aglutinar texto, audios, vídeos, tablas, imágenes, etc.
  • Todo esto nos permite crear páginas web a nuestro gusto, y sobre todo, vincularlas entre sí con hipervínculos.
  • Hay que tener en cuenta que HTML es un lenguaje de texto plano que necesita como visor un navegador web, y que su extensión debe ser siempre la de .html Ejemplo: index.html

Estructura o tags en HTML

Las etiquetas en HTML, se escriben de la siguiente manera:
  • Se escriben entre desigualdades, suelen ir en parejas y rodeando el texto al que aplica.
  • Tienen una etiqueta de aperta y otra de cierre.
  • La etiqueta de apertura contiene como mínimo el nombre de la marca o etiqueta, y la de cierre, empieza con el caracter / seguido del nombre de la etiqueta.

Estructura de una página web y comentarios

Comentarios en HTML y CSS

Los comentarios en HTML, se establecen de la siguiente manera:
  • Comenzaremos con el símbolo menor que '<' seguido de ! y de --
  • Introducimos el texto con el mensaje a comentar
  • Cerramos con la estructura -- seguido de '>'

Los comentarios en CSS, se hace de la siguiente manera:
Ponemos // seguido del texto que queramos comentar.

Estructura de un documento HTML

  • Los documentos HTML están dividos en dos grades bloques o zonas principales: head y el body
  • head: El head o cabecera, se caracteriza por ser la zona en donde almacenaremos información tal como:
    el nombre de la pestaña (title), favicon, librerías externas de CSS y JS, metadatos, idioma, etc.
  • body: Es donde vamos a introducir TODA la información de nuestra web: imágenes, texto, vídeo audio, formularios, etc.
