Secciones en HTML5

Cuando vamos a crear una página web, debemos tener en cuenta que esta puede estar
dividida en distintas secciones o partes, en las cuales, alojaremos distinto
contenido que se quiera mostrar.
En tecnologias como HTML4, se utilizaban principipalmente una serie de cajas o
elementos llamados div, para poder insertar información tal como: textos,
vídeos, imágenes, tablas, etc.
Estos div junto a etiquetas CSS, como pueden ser id (idenficadores) o class (clases)
nos permiten darle un nombre concreto así como una serie de atributos / características
concretas.
A continuación se muestra una estructura de la página con elementos div.

Con la llegada de HTML5, este tipo de estructura y etiquetas han dado lugar a una serie de
etiquetas propias en HTML5 que ya recogen los nombres que antes asignábamos a los ids y clases
en CSS para estas estructuras.

¿Para qué sirve cada etiqueta en HTML5?

  • Cabecera o Header: Esta etiqueta sirve para contener el título o elementos introductorios
    a nuestra web. Es la parte superior de una página o articulo.
  • Menú de Navegación o Nav:En HTML5 podemos agrupar enlaces a otras páginas o apartados,
    a través de la etiqueta nav. Con esta etiqueta por ejemplo podemos crear menús de una web,
    que permitan llevarnos a distintas secciones o apartados en la misma página o a webs externas.
  • Contenido Principal o Main: La etiqueta main es la que va a contener todo el contenido central
    de nuestra página web.
    IMPORTANTE: Esta etiqueta no sustituye a la etiqueta body del documento HTML5, sino que va dentro
    de esta. Recordar que esta etiqutea es la más importante para el usuario de nuestra página web.
  • Apartado temático o Section: Esta una etiqueta que nos permite agrupar contenido relacionado
    con un tema, normalmente incluyen un título.
  • Contenido Independiente o Article:: Esta una etiqueta que permite agrupar contenido que tiene
    sentido por sí solo, como puede ser una noticia o una publicación concreta.
  • Contenido secundario o Aside: Sirve para agrupar contenido que tiene información complementaria al principal.
  • Pie de página o Footer: Contiene información final como puede ser el autor, derechos de autor,
    enlcanes relacionados, etc.
  • address y hgroup: La primera se utiliza para indicar los datos de contacto de un autor o responsable del contenido.
    La segunda, se utiliza para agrupar un encabezado con un subtitulo o lema asociado.
    Recordar: hgroup se suele utilizar para agrupar un título y un subtítulo, mientras que header se utiliza para
    cuando hay metadatos asociados al título.

Diferencias entre una etiqueta Div y una etiqueta Span

En HTML5, podemos a parte de encontrarnos con las etiquetas anteriormente comentadas, con dos etiquetas
que podemos usar para nuestra estructura del documento web y que son las siguientes:
  • div:Esta etiqueta se utiliza para poder agrupar contendo en bloques
  • span:Esta etiqueta se utiliza para agrupar una parte de una línea
Ejemplo de una etiqueta div:

Mi perfil

Me llamo Raúl

Mis aficiones

Me gusta las nuevas tecnologías y sobre todo Linux, que es amor...


Ejemplo de etiqueta spam

Mi color favorito es el verde que es un color muy bonito


Como se puede ver en el ejemplo, la palabra "verde" aparece en color verde, y el resto de la frase
mantiene su formato.
  • div:. Se puede utilizar para agrupar bloques de contenido. Ejemplo: un recuadro de perfil
  • span Se utiliza para agrupar parte de una linea. Ejemplo: una palabra coloreada
Truco: div organiza bloques. Mientras que span permite trabajar con partes pequeñas de texto.
Hay que tener en cuenta que ninguno aporta por sí mismo un significado específico.
